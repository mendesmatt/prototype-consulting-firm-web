# Professional Portfolio — Marketing, Design & Web

> Professional web application prototype for business advisory and consulting services, built as a fully multilingual portfolio.

`HTML5` · `CSS3` · `JavaScript`

## 🇬🇧 English

**Segment:** Professional services & digital consulting

Professional web application prototype for business advisory and consulting services, built as a fully multilingual portfolio.

**Highlights**

- Multilingual interface (FR/EN/ES/PT) with saved preference
- Service areas: branding, software platforms, sites and apps
- Project gallery with lightbox and contact section

**Tech:** HTML5, CSS3, vanilla JavaScript.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
